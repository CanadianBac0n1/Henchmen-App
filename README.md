# Henchmen App

A static, multi-page website for the Department of Unapologetic Mischief and its suspiciously polished founder, Dr. Obscuro.

## Site map

- `index.html` — headquarters and primary calls to action
- `careers.html` — open roles, benefits, scheme generator, and local-only application simulation
- `about.html` — organization history and leadership
- `operations.html` — declassified case-study index
- `contact.html` — Formspree-powered contact form
- `ops_*.html` — individual operation dossiers
- `secret.html` — Konami Protocol easter egg

## Shared assets

- `site.css` contains the shared responsive, focus, navigation, and interaction refinements.
- `site.js` manages the current year and opt-in ambient audio.
- `dossier.css` keeps the declassified reports readable on small screens.
- `og.png` is the site-wide social-sharing card.

The site has no build step. Serve the directory with any static file server, or publish it directly through GitHub Pages.
